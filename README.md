# Multi-Agent Software Engineer

Human-supervised planning scaffold that turns a task into acceptance criteria, implementation steps, a test plan and risk notes. Deterministic, no API key required.

Run: `pip install -r requirements.txt`; `python -m software_engineer.cli "Add CSV export to customers"`; `pytest`.

It does not inspect repositories, generate patches, execute shell commands or modify code. High-impact tasks are flagged for human approval.

# Role contracts

Planner returns deliverables, criteria, steps and risks. Tester maps each criterion to a verification proposal marked `not_run`. Reviewer flags high-impact approval requirements. This baseline does not read a target repository, call a model, generate patches, execute commands or alter files. Future agents should use structured output schemas, sandboxed workspaces, tool allowlists, secret redaction, audit trails and human approval before side effects.
